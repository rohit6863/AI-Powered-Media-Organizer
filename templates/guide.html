Project Guide & Summary

How to Use This App

  1. Prepare your files: Gather the messy images (screenshots, memes, documents, etc.) you want to organize into a single folder on your computer.
  2. Upload: Click the "Upload & Sort Magic" button on the home page and select your folder.
  3. Let AI work: The AI will analyze the visual features of every single image in real-time. Please be patient, as this requires heavy computation!
  4. Download: Once finished, the app will automatically download a clean .zip file containing your newly categorized folders.

About the AIML Project

This application is the culmination of an Artificial Intelligence and Machine Learning (AIML) project designed to solve a real-world problem: digital clutter.

The Architecture

  • Feature Extraction: We use OpenAI's state-of-the-art CLIP (Contrastive Language-Image Pretraining) Vision Transformer to "look" at the images and convert their visual features into a dense mathematical vector.
  • Classification: A custom-trained Logistic Regression machine learning model takes those vectors and maps them into 7 distinct categories (e.g., id_cards, docs_and_notes, screenshots, memes).
  • Web Backend: A Python Flask server connects the raw ML inference pipeline to a beautiful, interactive web interface.

Tackling Dataset Bias

During development, we encountered and solved real-world ML problems such as Overlapping Decision Boundaries and Class Ambiguity. For example, the model initially confused Bank Passbooks with ID Cards, and Web UIs with Text Documents. Through a technique called Hard Negative Mining (feeding the AI its exact mistakes), we fine-tuned the training dataset to achieve a robust final accuracy of 90.00%.
